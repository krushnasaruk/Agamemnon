Integrating RL-NetCompress into Your PyTorch Project

Use our lightweight Python SDK to automatically compress custom models in 3 lines of code

1. Install & Import Python SDK

from netcompress import RLCompressor

# Initialize compressor with your PyTorch model and validation loader
compressor = RLCompressor(model=my_custom_model, val_loader=val_loader, target_accuracy=0.88)

# Execute autonomous RL architecture search
compressed_model = compressor.compress(episodes=30, agent_type="PPO")

# Export to ONNX format for deployment
compressor.export_onnx("./models/compressed_model.onnx")
print(compressor.get_summary())

2. Command Line Interface (CLI) Execution

# Train baseline and run 30 episodes of PPO search
python main.py --agent PPO --episodes 30 --train-baseline

# Launch visual dashboard server
python main.py --dashboard

3. ONNX Runtime Inference Deployment

import onnxruntime as ort
import numpy as np

# Load optimized ONNX model
session = ort.InferenceSession("./results/rl_discovered_model.onnx")
dummy_input = np.random.randn(1, 3, 32, 32).astype(np.float32)

outputs = session.run(None, {"input": dummy_input})
print("Inference output shape:", outputs[0].shape)
